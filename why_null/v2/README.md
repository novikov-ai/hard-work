# Зачем вам NULL ?

**SRTP** (statically resolved type parameters) 

## Генерико-подобные абстракции

Это абстракции уровня типов: работают на этапе компиляции, выражают алгебраические свойства ("умеет складываться", "умеет сравниваться"), не привязаны к предметной области.

| Свойство | F# | Go |
|---|---|---|
| **1. Выражают абстрактные свойства** | `let inline add x y = x + y` — компилятор через SRTP требует, чтобы тип поддерживал `+`, и это не имеет отношения ни к какому домену | `constraints.Ordered` — свойство "поддерживает `<`/`>`", годится для чисел, строк, чего угодно |
| **2. Спецификации бессрочны** | Контракт структурного равенства (`Equals`, `IEquatable<'T>`) — рефлексивность/симметрия/транзитивность, часть .NET с самого начала, не менялась | `sort.Interface` (`Len`, `Less`, `Swap`) — контракт не менялся с Go 1.0 (2009 год) |
| **3. Идентификация идиом** | `Option.bind` и `List.collect` — обе функции реализуют одну и ту же идиому "прогнать через функцию, которая возвращает контейнер, и расплющить результат" (bind), просто для разных контейнеров | `func Reduce[T, A any](s []T, init A, f func(A, T) A) A` — идиома "свернуть коллекцию в одно значение", написанная вручную поверх слайса |
| **4. Статическая типизация** | SRTP-ограничение проверяется компилятором до запуска — если тип не поддерживает `+`, код просто не скомпилируется | `func Max[T constraints.Ordered](a, b T) T` — то же самое, ошибка типов ловится на компиляции |
| **5. Полиморфизм времени компиляции** | `inline`-функция со SRTP не существует как единый скомпилированный код — компилятор разворачивает её под каждый конкретный тип отдельно, ещё на этапе компиляции | Компилятор Go тоже генерирует код под конкретные типы при инстанцировании дженерика (хотя технически это не чистая мономорфизация как в C++, а гибрид с частичным переиспользованием кода — GC shape stenciling) |
| **6. Механизм генерализации** | `'a list`, `'a option` — один и тот же контейнер работает для int, string, любого record-типа | `func Filter[T any](s []T, pred func(T) bool) []T` — одна функция фильтрации для любого слайса |

## Интерфейсо-подобные абстракции

Это абстракции про домен: живут в рантайме, выражают понятия предметной области ("платёжный шлюз", "стратегия сортировки"), реализации можно подменять и они со временем устаревают.

| Свойство | F# | Go |
|---|---|---|
| **1. Выражают понятия предметной области** | `type IPaymentGateway = abstract member Charge: Money -> Result` — обычный .NET-интерфейс, F# его прекрасно понимает | `type PaymentGateway interface { Charge(Money) error }` |
| **2. Реализации имеют срок действия** | Класс, реализующий `IPaymentGateway` для конкретного Stripe API, придётся переписать, когда Stripe поменяет SDK — сам интерфейс переживёт эту смену | `type StripeGateway struct{}`, реализующая `PaymentGateway` — та же история, реализация устаревает, контракт остаётся |
| **3. Конструирование паттернов** | Object expression — `{ new ISortStrategy with member _.Sort a = Array.sort a }` — паттерн Strategy без отдельного класса, просто конкретный экземпляр интерфейса на лету | Тот же Strategy через `type SortStrategy interface { Sort([]int) }`, но у Go нет `implements` — структура просто подходит по набору методов |
| **4. Динамическая реализация (рантайм)** | Какую конкретную реализацию `IPaymentGateway` подставить, решается в рантайме — через DI-контейнер или просто передачу параметра в функцию | Явная передача интерфейса в конструктор: `NewService(repo Repository)`, а какая именно реализация — решается в `main()` |
| **5. Динамический полиморфизм** | `gateway.Charge money` — вызов резолвится через рантайм .NET (vtable), в момент компиляции конкретный код ещё не известен | Вызов метода на интерфейсном значении в Go тоже резолвится в рантайме, через itable |
| **6. Механизм инкапсуляции** | Модуль с `private`-состоянием: `module Stack = let mutable private data = [] ...` — наружу торчат только `push`/`pop`, само хранилище скрыто | Неэкспортируемые (с маленькой буквы) поля структуры + экспортируемые методы — тот же принцип, скрыть представление и оставить только контракт |
